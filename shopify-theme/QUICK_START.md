# Quick Start Guide

Get your Sole Theory theme up and running in 10 minutes.

## 1. Upload Theme (2 minutes)

1. Zip the `shopify-theme` folder
2. Go to Shopify Admin > Online Store > Themes
3. Click "Add theme" > "Upload zip file"
4. Upload your theme

## 2. Basic Configuration (3 minutes)

### Header
- Click "Customize" on your theme
- In Header section:
  - Set logo text: "SOLE THEORY" (or your brand name)
  - Select main navigation menu

### Homepage Sections
- Hero Section: Set title, subtitle, and button link
- Featured Banner: Add promotional text
- Featured Collections: Select 2-3 collections to display

### Footer
- Add brand name and tagline
- Add social media links
- Select footer menu

## 3. Add Products (3 minutes)

Quick test setup:
1. Go to Products > Add product
2. Add 3-6 sample products with:
   - Title
   - Price
   - Image (at least 800x800px)
   - Description

3. Create a collection:
   - Go to Products > Collections
   - Create "All Products" or "Featured"
   - Add your products

## 4. Test & Publish (2 minutes)

1. Preview the theme
2. Test on mobile (use phone or browser dev tools)
3. Check:
   - Navigation works
   - Cart opens
   - Products display correctly
4. Click "Publish" when ready

## Done!

Your store is now live with the Sole Theory theme.
